# @almyty/connections

Renamed to [`@almyty/credentials`](https://www.npmjs.com/package/@almyty/credentials).

This package is a thin alias: `npx @almyty/connections <command>` runs
`npx @almyty/credentials <command>` with the same arguments. The old command
names (`connectors`, `connect`, `disconnect`) still work there, next to the
new ones (`services`, `add`, `delete`).
