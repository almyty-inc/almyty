# Changesets

Each file here describes a change to the `@almyty/*` packages that has not
been released yet. Add one with `npx changeset` in the PR that makes the
change. All twelve packages release together at one version.

How releases work, step by step: [docs/releasing.md](../docs/releasing.md).

`lerna.json` at the repository root is only the package list Changesets
reads. Lerna itself is not used.
