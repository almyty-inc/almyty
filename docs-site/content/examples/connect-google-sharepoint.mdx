# Put your Google Drive or SharePoint to work

If your team's knowledge lives in Google Drive or SharePoint, an assistant can use it: find the right document, read it, answer questions from it, and write a summary back into a folder. "What's in the Q3 folder?" or "draft this week's summary from these documents" then happens without anyone opening Drive.

almyty has no ready-made Google or Microsoft connector. You connect their APIs the same way you connect any other system, which takes a technical person to set up once.

## What you need

- Access to Google's Drive API or Microsoft Graph (the API behind SharePoint and OneDrive), with an app registered on their side.
- Someone technical for the one-time setup below.

## How to build it

1. **Connect the documents.** Open **APIs** and click **Connect an API**. Either pick **OpenAPI / Swagger** and give the API description (Microsoft publishes one for Graph), and its operations (list files, read a file, update a file) become tools. Or pick **SDK / npm**, add Google's or Microsoft's official package (`googleapis`, `@microsoft/microsoft-graph-client`), then make a tool for each method you need under **Tools**, **Create tool**, **SDK / npm package**.
2. **Sign in once.** These services use OAuth (a "Sign in with Google/Microsoft" style approval instead of a password). Save the app's details in [Credentials](/credentials) with **Add credential**. On the Google or Microsoft side, allow only the folders or sites the assistant should see.
3. **Create the assistant.** Open **Agents**, click **Create agent**, switch to **Autonomous**, and write the job in **Instructions**: "search the shared drive, read the relevant documents, and answer, summarise or draft". Under **Tools and APIs**, pick the Drive or Graph tools. Save.
4. **Decide how it's used.** People can ask it on Slack (add a **Slack** channel on its **Channels** tab), or it can run on its own: on the agent's **Overview** tab, turn on **Schedule**, for example once a day for a digest of new documents.
5. **Write back.** With an "update file" or "create file" tool, it can save its summary where the team already looks.

## Ideas

- Keep it to one shared drive or one SharePoint site.
- For a handful of reference documents, you can skip the connection: add them on **Memory** with **Add memory** (kind **Document**) and set the assistant's memory to **Shared by all agents**.
