# Answer product questions from your help center, in Slack

## What you'll build

A Slack assistant that answers your colleagues' product questions from your Intercom help center. Someone mentions it in a channel, it searches the help center, answers in the thread with the steps and the plan limits exactly as the article states them, and links the article. When no article covers the question, it says so instead of guessing and opens a "Docs gap" ticket in Intercom, so your docs team sees which articles to write next.

![The assistant answering in a Slack thread, with the steps from the article and a link to it](/screenshots/examples/docs-deflection-bot/00-slack-thread.png)

This guide builds it for Parcelwise, a made-up company that sells shipping software to online shops. The screenshots come from a test installation with made-up people, so web addresses in them start with `http://localhost`. Yours start with your almyty address. It takes about 30 minutes.

## What you need

- **An almyty account**, and the key of an AI provider such as OpenAI.
- **An Intercom workspace** with your help center in it, and admin rights to create an app in Intercom's **Developer Hub**.
- **A "Docs gap" ticket type in Intercom.** In Intercom, under **Settings**, **Tickets**, create a ticket type named `Docs gap` in the **Back-office** category. The assistant files unanswered questions under it.
- **A Slack workspace** where you may create an app.

## 1. Connect an AI model

In the sidebar, open **Models** and click **Connect a provider**. Set **Name** to `OpenAI`, pick **OpenAI** under **Provider**, paste your key under **API key** and click **Save**. almyty checks the key and lists the models you can use.

![Connect a provider, with OpenAI picked and the key pasted](/screenshots/examples/docs-deflection-bot/01-connect-model.png)

You do this once for your organization. Every assistant can use these models.

## 2. Get an Intercom access token

**In Intercom**, open **Settings**, **Integrations**, **Developer Hub**, click **New app**, name it `almyty docs assistant` and pick your workspace. In the app, open **Configure**, **Authentication**:

- Under permissions, make sure the app may **Read and list articles**, **Read tickets** and **Write tickets**. That is all it needs.
- Copy the **Access token**.

## 3. Connect Intercom

In almyty, open **APIs**, click **Connect an API** and pick **OpenAPI / Swagger**. Under **Link to the description**, paste Intercom's own published description of its API:

```
https://raw.githubusercontent.com/intercom/Intercom-OpenAPI/main/descriptions/2.11/api.intercom.io.yaml
```

![The link to Intercom's API description, pasted](/screenshots/examples/docs-deflection-bot/02-intercom-link.png)

Open **Advanced** and set **Name** to `Intercom`, so the tool names match the ones below. If your Intercom workspace is hosted in Europe, also set **Address** to `https://api.eu.intercom.io` (Australia: `https://api.au.intercom.io`). Click **Connect API**.

almyty reads the description and makes a tool for each thing Intercom's API can do: 108 of them. Intercom sends its key as a bearer token, and almyty has already picked that. Under **Credential**, click **Create one here**, set **Name** to `Intercom (Parcelwise help center)`, paste the access token under **Key** and click **Save**.

![Finish connecting Intercom: 108 tools, and the access token pasted](/screenshots/examples/docs-deflection-bot/03-intercom-token.png)

The token is stored under **Credentials**, encrypted, and is only ever sent to Intercom.

## 4. Create the assistant

Open **Agents**, click **Create agent** and pick **Autonomous** at the top: you describe the job and the assistant works out the steps.

1. Click the name and replace it with `Docs assistant`.
2. Under **Work mode**, open **Model** and pick **gpt-4o** (or another model you connected).
3. **Personality & style**: `Short and plain. Answers first, then how. No filler and no exclamation marks.`
4. **Instructions**:

```
You answer questions from Parcelwise colleagues about the product, using only the Parcelwise help center in Intercom.

For every question:
1. Search the help center for it.
2. If an article answers it, answer in a few lines and end with "Source:" and a link to the article. Copy plan limits and carrier names exactly as the article says them.
3. If no article answers it, do not guess. Open a ticket of the type "Docs gap" for the docs team, with the question as its title and docs@parcelwise.example as the contact, and say that you did.

Never invent a feature, a limit or a price that is not in an article.
```

Replace `Parcelwise` with your company and `docs@parcelwise.example` with the address of whoever owns your docs (Intercom needs a contact on every ticket).

![The Docs assistant with its personality and instructions](/screenshots/examples/docs-deflection-bot/04-agent.png)

## 5. Give it three Intercom tools

Scroll to **Capabilities**. Under **Tools and APIs**, type in **Search tools** and tick these three:

| Tool | What it does |
|---|---|
| **Search for articles** (`intercom_search_articles`) | Searches the help center (`GET /articles/search`) |
| **List all ticket types** (`intercom_list_ticket_types`) | Finds the id of your "Docs gap" type |
| **Create a ticket** (`intercom_create_ticket`) | Opens the Docs gap ticket |

Leave the other 105 unticked. The assistant can use only what is ticked here, so it cannot, for example, edit or delete an article.

![The three Intercom tools picked under Capabilities](/screenshots/examples/docs-deflection-bot/05-tools.png)

Click **Save** at the top right, go back to the agent (the arrow at the top left) and click **Activate**.

## 6. Try it

On the agent's **Overview** tab, find **Try it**. Type `Can customers print DHL return labels in bulk?` and press Enter.

![The answer, with the steps from the article and the source link](/screenshots/examples/docs-deflection-bot/06-try-answer.png)

It searched the help center, found "Create return labels in bulk" and answered:

> Yes. Make return labels for up to 250 orders at once and email them to your customers.
>
> 1. Open Orders and tick the orders (up to 250 at a time).
> 2. Click Actions, then Create return labels.
> 3. Pick the carrier. Bulk return labels work with DHL Parcel, DPD, UPS and PostNL.
> 4. Choose Email the label to the customer or Download as one PDF.
>
> Bulk return labels are part of the Growth and Business plans. On the Starter plan you create return labels one order at a time.
>
> Source: Create return labels in bulk

Now ask something the help center does not cover: `Is there a rate limit on the Parcelwise REST API?`

![No article covers it, so it opened ticket #381 for the docs team](/screenshots/examples/docs-deflection-bot/07-try-ticket.png)

It found no article, looked up the "Docs gap" ticket type, opened ticket #381 with the question as its title, and answered: *I could not find this in the help center, so I will not guess. I opened ticket #381 ("Docs gap") for the docs team, and they will answer you here.* Every run is kept under the **Runs** tab with each Intercom call it made.

## 7. Put it in Slack

**In Slack**, go to **api.slack.com/apps**, click **Create New App**, **From scratch**, name it `Docs assistant` and pick your workspace. Then:

- **OAuth & Permissions**, **Bot Token Scopes**: add `app_mentions:read`, `chat:write`, `im:history` and `users:read`. Click **Install to Workspace** and copy the **Bot User OAuth Token** (it starts with `xoxb-`).
- **Basic Information**: copy the **Signing Secret**.

**In almyty**, open the assistant's **Channels** tab, click **Add channel** and pick **Slack**.

1. Open **Advanced** (one workspace, with a bot token) and click **Create one here**.
2. Open **More options**, choose **Bot token**, set **Name** to `Slack bot (Parcelwise)`, and paste the **Bot user OAuth token** and the **Signing secret**. Click **Save**.

![The Slack bot token and signing secret](/screenshots/examples/docs-deflection-bot/08-slack-keys.png)

3. Click **Save** at the bottom, then **Publish**. The page shows a **Callback URL**.

![The Slack channel, live, with its callback URL](/screenshots/examples/docs-deflection-bot/09-slack-live.png)

4. **In Slack**, open **Event Subscriptions**, turn it on, paste the Callback URL as the **Request URL**, and under **Subscribe to bot events** add `app_mention` and `message.im`. Click **Save Changes**.
5. Invite it to the channel where people ask, for example `#ask-product`: type `/invite @Docs assistant` there.

## 8. Let it use Intercom for everyone who asks

When you try it yourself, it uses your own access. When a colleague asks in Slack, it may use only the accounts you have given to the assistant itself. Until then it answers "I don't have access to Intercom" instead of guessing.

Go back to the assistant's **Overview** tab. Under **Access**, it lists what it has not been given yet. Click **Let this agent use Intercom (Parcelwise help center)**.

![Access: Intercom not given yet, with the button to give it](/screenshots/examples/docs-deflection-bot/10-access.png)

Now mention it in Slack: `@Docs assistant can customers print DHL return labels in bulk? A prospect asked on a call.` It answers in the thread, as in the picture at the top of this page. A line at the start of its reply tells people they are talking to an AI assistant.

## Make it yours

- **A different help center.** Zendesk, HubSpot, Freshdesk and most other help desks publish an API with a search endpoint. Connect its description the same way under **APIs**, add its key, and tick its "search articles" and "create ticket" tools instead.
- **Answer customers, not colleagues.** Add a **Website widget** or **Web chat** channel instead of Slack (see [Customer support assistant](/examples/customer-support-assistant#7-put-it-on-your-website)). Then the Access step decides what visitors may reach.
- **Write the missing articles.** Every week, filter your Intercom tickets by the "Docs gap" type: that is the list of questions your help center does not answer yet.
- **A second opinion.** Under **Work mode**, a stronger model can check every answer against the article before it is posted. See [Autonomous agents](/agents/autonomous).

## If something goes wrong

| What you see | What to do |
|---|---|
| In Slack it answers **I don't have access to Intercom** | Step 8: on the **Overview** tab, under **Access**, click **Let this agent use Intercom ...**. |
| Tools fail with **401 Unauthorized** | The access token is wrong or was regenerated. Open **Credentials**, find `Intercom (Parcelwise help center)` and replace the key. |
| Tools fail with **403** on tickets | The Intercom app lacks **Write tickets**. Add it under **Configure**, **Authentication** in the Developer Hub. |
| It never finds anything, though the article exists | A European or Australian workspace needs its own API address: open the Intercom API in almyty and set **Address** (step 3). |
| Slack never answers | Check that the bot is invited to the channel, that **Event Subscriptions** shows the Request URL as verified, and that `app_mention` is subscribed. |
| Creating the ticket fails with **ticket_type_id not found** | Create the "Docs gap" ticket type in Intercom (see What you need). |
