# Scheduling

A schedule runs an agent by itself, over and over, at a fixed interval. Use it for jobs nobody should have to remember: a nightly summary of support tickets, an hourly check that your systems are healthy, a weekly report.

![The Schedule config on an agent: enable, interval in minutes, optional input JSON](/screenshots/schedule-config.png)

## Set up a schedule

1. Open the agent and stay on its **Overview** tab.
2. On the **Schedule** card, turn on **Enable schedule**.
3. Set **Interval (minutes)**: how often it runs, from once a minute to once a year. For once a day, enter 1440.
4. Optionally fill in **Input JSON**: the same starting information handed to every run, such as `{ "days": 1 }`.
5. Click **Save schedule**.

The card then says when the next run is due, counted from the last run.

| To run it | Interval |
|----------|----------|
| Every 5 minutes | 5 |
| Every 15 minutes | 15 |
| Every hour | 60 |
| Every day | 1440 |
| Every week | 10080 |

## Stop a schedule

On the **Schedule** card, turn **Enable schedule** off. The runs it already made stay in the agent's history.

## Good to know

- The agent must be active for scheduled runs to happen. Pausing the agent pauses its schedule; activating it again resumes it.
- A failed run does not stop the schedule; check the **Runs** tab for errors.
- almyty pauses a schedule by itself when it cannot run properly: when the model it uses no longer exists at the vendor, when the member who owns the agent leaves the organization, or when that owner can no longer run it. The agent shows why, and turning the schedule back on starts it again.
- Scheduled runs are listed on the **Runs** tab next to the ones started by hand.

## What it costs

Before turning on a frequent schedule, look at **Avg cost per run** on the agent's **Overview** tab and multiply it by the number of runs. A schedule every 60 minutes runs 720 times in a 30-day month; every 5 minutes, 8,640 times. [Run limits](/run-limits) and [cost governance](/cost-governance) can cap what an agent spends.

## For developers

Scheduled runs carry `triggerType: "scheduled"` in their metadata. Review them from the terminal:

```bash
$ npx @almyty/agents runs daily-reporter
```

Filter to the failed runs with `--json` and `jq`:

```bash
$ npx @almyty/agents runs daily-reporter --json \
    | jq '[.[] | select(.status == "failed")]'
```

The schedule is set with `POST /agents/:id/schedule` and removed with `DELETE /agents/:id/schedule`; see the [Agents API](/api-reference/agents-api).

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `enabled` | boolean | Yes | Turn the schedule on or off |
| `intervalMinutes` | number | When enabling | How often to run, 1 to 525,600 (one year) |
| `input` | object | No | Static input passed to each run |

Runs per 30-day month = `(60 * 24 * 30) / intervalMinutes`.
