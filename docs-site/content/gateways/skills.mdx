# Skills Gateway

Drop your tools into any AI coding agent as installable skills. A Skills gateway renders each tool as a `SKILL.md` file following the [Agent Skills](https://agentskills.io) specification. The almyty Skills CLI installs and auto-injects those files into 30+ agents, including Cursor, Windsurf, Claude Desktop, and GitHub Copilot.

![Gateway detail page](/screenshots/gateway-detail.png)

## Share the tools

1. Open **Gateways → Share tools** (`/gateways/new`)
2. Under **What to share**, pick a whole API or single tools
3. Name it; the address follows from the name (**Advanced** changes the path and who can use it)
4. Click **Share** and copy the access key

Each tool the gateway serves becomes one `SKILL.md` file; **Tool scoping** on the gateway detail page changes which. Copy the gateway slug: you will use it with the Skills CLI.

![Assigning tools on the gateway Tools tab](/screenshots/gateway-detail-tools.png)

## Install with the Skills CLI

Install the gateway's skills into your local agents:

```bash
npx @almyty/skills install @acme/my-skills
```

Authenticate first if needed:

```bash
npx @almyty/skills login
npx @almyty/skills login --token your-api-key
```

### Watch mode

Poll the gateway every 30 seconds and refresh SKILL.md files when tools change:

```bash
npx @almyty/skills watch @acme/my-skills
```

Stop with Ctrl+C or:

```bash
npx @almyty/skills stop
```

### List and remove

```bash
npx @almyty/skills list
npx @almyty/skills remove @acme/my-skills
```

The CLI writes SKILL.md files to each agent's skill directory and registers them for auto-loading.

## SKILL.md format

Each tool produces a markdown file whose frontmatter carries only `name`, `description`,
and a `metadata` block:

```yaml
---
name: get_users
description: Retrieve a list of users with pagination
metadata:
  author: almyty
  generated: "true"
  toolId: "d3b0...-tool-uuid"
  version: "1"
---
```

The `toolId` is what `almyty-skills run` resolves against, so a skill keeps working after
a rename. Under the frontmatter the file has a `# get_users` title, the tool's
description, then `## When to use`, `## HTTP endpoint`, `## Parameters`, `## Example`,
and `## Invocation` sections.

`## HTTP endpoint` names the **upstream** API the tool wraps — for example
`GET https://api.example.com/users` — not an almyty URL. Agents do not call it directly;
`## Invocation` gives them the Skills CLI command, which authenticates with your stored
almyty credentials and runs the tool through the gateway:

```bash
npm i -g @almyty/skills   # one-time, skip if already installed
almyty-skills run acme/my-skills/get_users --limit 10
```

`npx -y @almyty/skills run ...` works too, at roughly a second of startup overhead per
call.
